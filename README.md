# 🧠 Deep Learning Projects

A collection of Deep Learning projects built using TensorFlow, Keras, Python, and Jupyter Notebook. This repository demonstrates Artificial Neural Networks (ANN), Convolutional Neural Networks (CNN), and Natural Language Processing (NLP) for solving real-world problems.

---

## 📌 Repository Overview

This repository showcases end-to-end Deep Learning projects, including data preprocessing, model training, evaluation, and prediction using modern deep learning techniques.

---

# 📂 Projects

## 1. Customer Churn Prediction Using ANN
- Predict customer churn using an Artificial Neural Network (ANN).
- **Dataset:** `Churn_Modelling.csv`
- **Techniques:** Data Preprocessing, ANN, Binary Classification

---

## 2. Fake News Detection Using NLP
- Detect fake news articles using Natural Language Processing and Deep Learning.
- **Techniques:** Text Preprocessing, Tokenization, TF-IDF/Embeddings, NLP Classification

---

## 3. Waste Material Classification
- Classify waste materials into different categories using image classification.
- **Techniques:** CNN, Image Processing, Computer Vision
